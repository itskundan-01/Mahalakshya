# Assets Directory

This directory contains images and other assets needed for the MahaLakshya application.

## Required Images

1. `trading-dashboard.webp` - Trading dashboard screenshot for the hero section
2. `ai-dashboard.webp` - AI Finance Manager dashboard screenshot

For best results:
- Hero image size: 800x600px (16:9 ratio)
- AI dashboard image size: 800x600px (16:9 ratio)

## Placeholder Images

Until you have your own screenshots, you can use:

1. Free stock images from sites like Unsplash, Pexels or Pixabay
2. Trading dashboard templates from sites like UI8 or CreativeMarket
3. AI-generated images from services like Midjourney or DALL-E

## Image Optimization

Before adding images to this directory, optimize them:
- Use WebP format for better compression and quality
- Compress images using tools like TinyPNG, ImageOptim or Squoosh
